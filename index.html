01
TECHNICAL NATURE

按技术本质分类

先看它凭什么工作，而不是叫什么名字。技术本质决定能力边界，名字只决定它出现在什么场景里。

Nº 01 SKILL

技能

一套可以反复复用的操作说明或工作流。它不自己决定目标，只把「怎么把某件事做好」写成可以照着执行的步骤。

例合同审查 · 内容工厂
Skill ｜ 技能、技艺 —— 可复用的能力单元。
Nº 02 AGENT

智能体

能自主感知、决策、调用工具、完成目标的系统。目标由人给出，路径由它自己拆。

  • PERSONAL AGENT个人智能体：长期只服务一个人，记住他的偏好和历史。
  • DIGITAL EMPLOYEE数字员工：企业版的个人智能体，把「服务一个人」换成「承担一个岗位」。
Agent ｜ 代理人、行动者 —— 能自主行动的系统。
Nº 03 MULTI-AGENT

多智能体协作

多个 Agent 分工配合，把一件复杂的事切成几段，由不同角色分别推进，最后汇到一处。

多 Agent 团队Agent 小队专家团专家团队
Multi-Agent ｜ multi（多）+ agent（智能体）。
Nº 04 COPILOT

副驾驶

人主导、AI 辅助。它嵌在你正在用的工具里，做补全、改写、检查这类贴身动作，但不接管整件事。

场景写邮件 · 改代码 · 审文档
Copilot ｜ co（共同）+ pilot（驾驶者）—— 副驾驶。

04
KEY DISTINCTIONS

三组关键辨析

最容易混的三组词，逐对拆开。每组只问一句：谁在掌握主动权。

技术本质 · SUBSTANCE

Agent智能体

能自主感知、决策、行动的系统。目标是别人给的，步骤是自己想的。

VS
产品包装 · PACKAGE

Bot机器人

有固定身份、长期记忆、能定时开工的 Agent。用户看到的是角色，不是内核。

Bot 通常是 Agent 的一种呈现方式，但 Agent 不一定是 Bot。
辅助 · ASSIST

Copilot副驾驶

人握方向盘，AI 只在当前这一步帮忙：补全、改写、检查。

VS
自主 · AUTONOMY

Agent智能体

你给一个目标，它自己拆步骤、调工具，一步步往前推。

Copilot 帮你做这一步，Agent 替你把这件事做完。
单兵 · SOLO

单 Agent一个人干

一个角色从头做到尾，链条短，适合线性、边界清楚的任务。

VS
组队 · TEAM

多 Agent多人分工

有人统筹、有人执行、有人汇总，适合环节多、需要并行的复杂项目。

团队的价值不在「更多」，而在「分工」与「有人收口」。
MNEMONIC · 记忆口诀

Agent 是技术本质，Bot / 伙伴 / 副驾驶 是产品包装。

Copilot 帮你写，Agent 帮你干，多 Agent 团队帮你搞定一整套项目。

06
GLOSSARY

术语对照表

页面出现过的英文词，逐条对照：中文译名、词义来源、在此处的具体含义。

核心术语

CORE TERMS
Agent名 · NOUN
智能体 / 代理人

能自主感知、决策、调用工具、完成目标的系统。词源为拉丁语 agere，「去做、驱动」，原义是「执行者、行事者」。

Skill名 · NOUN
技能 / 技艺

一套可反复复用的操作说明或工作流。在智能体语境里，它是可被调用、可被继承的能力包，而不是一个独立的主体。

Multi-Agent名 · NOUN
多智能体（协作）

multi 意为「多」，agent 意为「智能体」。指多个智能体分工配合，共同推进同一件复杂任务。

Copilot名 · NOUN
副驾驶 / 辅助智能

co 意为「共同」，pilot 意为「驾驶者」，合起来即「副驾驶」。指人主导、AI 在当前步骤上提供补全、改写、检查的辅助形态。

Personal Agent名词短语
个人智能体

personal 意为「个人的」。长期只服务同一个人、持续积累其偏好与历史的智能体。

Digital Employee名词短语
数字员工

digital 意为「数字的」，employee 意为「雇员」。企业版的个人智能体，服务对象从「一个人」换成「一个岗位」。

Bot名 · NOUN
机器人 / 机器人角色

robot 的缩写，原义为「机器人」。在产品层，指有固定身份、长期记忆、能定时开工的智能体；有时也泛指任何自动化对话程序。

Squad名 · NOUN
小队 / 班组

指人数较少、结构扁平的一组协作者。用在智能体产品上，强调「几个角色刚好够用」。

Team名 · NOUN
团队

为同一目标组织起来的一组角色，通常含统筹、执行、汇总的分工。

Expert Group名词短语
专家团

expert 意为「专家」，group 意为「组」。指按专业领域划分、各管一摊的多智能体组合。

产品名

PRODUCT NAMES
Dots产品名 · OPENAI
点（复数）

dot 意为「点」。作为产品名不直译，此处指 OpenAI 的云端个人智能体入口命名。

Grok / Grok Bot产品名 · xAI
彻底理解 / 机器人

grok 出自科幻作家海因莱因小说，意为「彻底地、直觉地理解」，现为科技圈常用词。Bot 即机器人，合起来指该平台的角色化智能体命名。

Muse产品名 · META
缪斯 / 灵感

源自希腊神话中掌管文艺的九位缪斯女神，引申为「灵感、启示」。此处作为个人智能体产品名使用。

Claude Duet产品名 · ANTHROPIC
二重奏

Claude 为 Anthropic 的 AI 助手名称；duet 意为「二重奏、双人表演」，暗示人与 AI 两个角色同台协作。

Cue产品名 · MANUS
提示 / 暗号

原指给演员的提词或行动信号，引申为「恰到好处的提示」。此处作为产品命名使用。

Partner / Work Buddy通用叫法
伙伴 / 工作搭子

partner 意为「伙伴」，buddy 意为「哥们、搭子」。两者都是把智能体包装成「同事关系」而非「工具」的叫法。
